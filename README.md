# Nanyang Film House 
*IE4727 Web Application Design — NTU*

Nanyang Film House is a campus cinema ticketing web application developed using HTML, CSS, JavaScript, PHP and MySQL. The platform allows users to browse movies, select screening sessions, book cinema tickets and submit student-produced films for review.

## Key Features
- **Movie Catalogue:** Browse mainstream movies, student films and upcoming campus screenings.
- **Cinema Booking:** Select screening dates, locations and available seats through an interactive seating plan.
- **Mock Payment:** Validate payment information and generate booking confirmations.
- **Email Acknowledgement:** Generate booking confirmation emails using FakeSMTP in a local testing environment.
- **My Account:** View upcoming, past and cancelled bookings, manage cancellations and track film submissions.
- **Film Submission:** Submit film information, viewing links and posters for administrative review.
- **Admin Dashboard:** Approve or reject student film submissions.

## Technologies Used
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Development Environment:** XAMPP
- **Email Testing:** FakeSMTP
- **Design:** Figma

## Note
User accounts are preconfigured in MySQL for the coursework demonstration. Booking email acknowledgements are captured locally using FakeSMTP rather than delivered to external recipients.

## Project Scope
This application was developed as part of NTU's IE4727 Web Application Design coursework. Payment processing is simulated, and the website is intended for local academic demonstration rather than commercial deployment.
